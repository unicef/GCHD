# AGENTS.md: UNICEF Global Child Hazard Database

Guidance for AI agents and LLMs working with this catalog. Generated by STAC_catalog/gchd_stac/docs.py.

## Overview

The **Global Child Hazard Database (GCHD)** brings together global, gridded layers of the climate, environmental, geophysical and conflict hazards that children are exposed to: floods, tropical storms, droughts, heatwaves, fire, sand and dust storms, air pollution, malaria, landslides, earthquakes, volcanoes and conflict. It adds the Multi-Hazard Intensity (MHI) index, WorldPop 2025 population grids (under 18 and all ages, female, male and total), harmonised administrative boundaries (ADM0/1/2), hazard-exposure statistics per administrative unit, and the locations of infrastructure that serves children, starting with schools from Giga.

## How the catalog is organised

- Static STAC 1.1 catalog conforming to the Portolan profile v0.2.0, served from GitHub Pages: https://unicef.github.io/GCHD/STAC_catalog/stac/catalog.json
- Root -> sub-catalogs (`hazards/<theme>`, `multi_hazard`, `population`, `boundaries`, `exposure`, `infrastructure`, `reference`) -> one Collection per dataset. Every Collection has a `data` asset; collections made of many files (river flood tiles, WorldPop countries) also have items and an `items_parquet` index.
- Data files are on Azure Blob Storage (https://unidatadapmclimatechange.blob.core.windows.net/public/), public, with HTTP range requests and CORS: stream them, no download or credentials needed.
- No `/search` endpoint (static catalog): walk `child` links, use the table below, or filter an `items_parquet` index.
- CRS: EPSG:4326 everywhere. Rasters are COGs (or GDAL VRTs over COGs); tables are (Geo)Parquet.
- Each Collection has its own AGENTS.md with access code, field notes and join keys.

## Finding a collection

```python
import pystac
cat = pystac.Catalog.from_file("https://unicef.github.io/GCHD/STAC_catalog/stac/catalog.json")
col = next(c for c in cat.get_all_collections() if c.id == "tropical_storm_100yr_giri_2024")
url = col.assets["data"].href
```
