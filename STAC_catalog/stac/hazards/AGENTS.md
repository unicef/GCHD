# AGENTS.md: Hazards

Guidance for AI agents and LLMs working with this catalog. Generated by STAC_catalog/gchd_stac/docs.py.

## Overview

Global gridded hazard layers, grouped by hazard theme. Each layer is one collection whose `data` asset is a Cloud-Optimized GeoTIFF (the river flood layer is 264 tiles with a VRT mosaic).
